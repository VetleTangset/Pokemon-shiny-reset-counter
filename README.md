# Pokemon shiny reset counter

A very simple reset counter for shiny hunting

## Installation

Use the package manager [pip](https://pip.pypa.io/en/stable/) to install pynput which is needed.

```bash
pip install pynput
```

## Usage

Check if your reset buttons are correct in reset_sequence(), these should be set to the same keys as what makes a soft reset happen in you pokemon emulator
